# Дзюдо: подготовка к экзамену на пояс

Бесплатный сайт для подготовки к экзамену на пояс по дзюдо: справочник техник в виде карточек и
пробные тесты. Всё открыто, без регистрации и оплаты.

Основа контента — официальная классификация Кодокана / IJF (68 нагэ-вадза + 32 катамэ-вадза),
без привязки к поясам. Программы поясов по странам подключатся позже отдельным слоем `syllabi`.

> Сайт не заменяет тренера. Требования к экзамену определяют федерация и додзё.

## Стек

Next.js 16 (App Router, статический экспорт) · React 19 · TypeScript · Tailwind CSS 4 · next-intl ·
ESLint · Playwright + axe · pnpm. Бэкенда и БД нет: данные — JSON в репозитории, состояние
пользователя — localStorage.

## Разработка

```bash
pnpm install
pnpm dev            # http://localhost:3000
pnpm run lint
pnpm run typecheck
pnpm run test:unit
pnpm run test:e2e
pnpm run build      # статический сайт в out/
```

Правила разработки — [AGENTS.md](AGENTS.md).

## Структура

| Путь | Что там |
| --- | --- |
| `data/judo-dataset.json` | Набор данных v0.2: техники, основы, группы Гокё |
| `docs/dataset/` | Прошлая версия с программой поясов CBJ и скрипты сборки набора |
| `src/lib/dataset/` | Типы и выборки из набора данных |
| `src/lib/quiz/` | Движок тестов: генерация вопросов из базы техник |
| `src/app/` | Страницы: главная, `/techniques/[slug]`, `/groups/[group]`, `/gokyo/[n]`, `/quiz`, `/about` |
| `messages/ru.json` | Строки интерфейса |

## Деплой

`pnpm run build` → папка `out/` на Cloudflare Pages или Netlify (команда сборки `pnpm run build`,
каталог `out`). Адрес сайта для sitemap — переменная `NEXT_PUBLIC_SITE_URL`.

## Лицензия контента

Тексты карточек и вопросы — собственные. Названия и классификация техник — общедоступная
номенклатура Кодокана.
